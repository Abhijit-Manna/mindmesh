3. Cross-Discipline Technical Consistency & Harmonization Audit

  • Protocol Alignment: The API contract (FastAPI/OpenAPI) acts as the single source of truth for the frontend (React) and backend services.
  • Data Model Consistency: The PostgreSQL schema is strictly enforced via Alembic migrations, ensuring that the database layer remains the authority for state, while Redis serves purely as an ephemeral cache.
  • DevOps Harmony: CI/CD pipelines are fully integrated with security tooling (Trivy, Gitleaks, Cosign). Every build is automatically tested against a transient database, ensuring that code-level changes never break the schema or core business logic.

4. Data Residency, Security & Regulatory Compliance (India)

  • Sovereignty: All resources are pinned to AWS ap-south-1. No data replication occurs outside of the Indian jurisdiction.
  • DPDP Compliance:
    • PII/PHI encryption is mandatory at rest using AWS KMS (CMK).
    • Automated logging via CloudTrail and CloudWatch creates an immutable audit trail for system access.
    • Data lifecycle management is implemented in S3 to facilitate the "Right to be Forgotten" via automated deletion/purging policies.
  • Isolation: The network topology enforces absolute isolation: Compute resources reside in private subnets with zero public ingress, and the RDS instance is contained within an isolated, non-routable subnet.

5. TCO & Cloud Sizing Recommendations

To balance the MVP requirement with future growth, the following sizing strategy is recommended for the initial 10,000 users/day:

  • Compute:
    • ECS Fargate (Task sizing): 2 vCPU / 4 GB RAM per task. Start with 3 concurrent tasks across 3 AZs for High Availability. Configure auto-scaling to trigger at 60% CPU utilization.
  • Storage & Database:
    • RDS: db.t4g.medium (Multi-AZ) is sufficient for initial transactional loads.
    • ElastiCache (Redis): cache.t4g.small is adequate for session management and hot-data caching.
  • Cost Optimization (Day-2 Operations):
    • Compute: Leverage Fargate Spot instances for non-critical Background Workers (Notification, Invoicing) to reduce compute costs by ~60%.
    • Storage: Implement S3 Lifecycle Policies to move documents older than 90 days to S3 Standard-IA or Glacier to minimize costs.
    • Reserved Instances: Transition to 1-year reserved instances for RDS once usage patterns stabilize after Month 3.
